# 资源库模板

## 知识点模板
每个知识点一个文件，放在 `资源库/知识点/`，按模块子目录归档。

```markdown
# 知识点：<名称>
- 所属模块：
- 课标要求：
- 核心概念：
- 关键结论：
- 常见易错点：
- 例题 / 链接：
```

## 题库模板
每道题一个条目，放在 `资源库/题库/`。

```markdown
- 知识点：<名称>
- 题型：单选 / 多选 / 填空 / 读程 / 程序设计
- 难度：易 / 中 / 难
- 题干：
- 选项（若选择）：A / B / C / D
- 答案：
- 解析：
- 适用课时：
```

## 课程结构（高中信息科技模块示例）
| 模块 | 说明 |
|------|------|
| 数据与算法 | 数据、算法、程序设计基础 |
| 信息系统与网络 | 信息系统、网络协议、信息安全 |
| 程序设计与计算思维 | Python 编程、算法思维 |
| 数据管理与分析 | 数据库、数据处理、可视化 |
| 人工智能初步 | 机器学习、AI 应用 |
| 信息系统与社会 | 信息社会、信息社会责任 |
