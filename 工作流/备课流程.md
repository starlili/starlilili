# 备课工作流

> 学科：高中信息科技

## 一节课的标准备课流程

### 1. 定位课标
- 明确本课对应的课程标准条目（数据与算法 / 信息系统与网络 / 程序设计与计算思维 / 数据管理与分析 / 人工智能初步 / 信息系统与社会）。

### 2. 填写教案模板
- 打开 `工作流/模板/教案模板.md`，填写：课题、课时、教学目标（四维）/ 重难点 / 教学过程 / 板书设计。

### 3. 准备课件与学案
- 课件：`备课材料/课件/`
- 学案：`备课材料/学案/`

### 4. 配套练习与检测
- 从 `资源库/题库/` 抽题，放入 `作业与测验/作业/` 或 `作业与测验/测验/`。

### 5. 归档
- 按「模块/单元/课时」三级命名归档到 `备课材料/`。

## 命名规范
`<模块>-<单元>-<课时>-<内容>.md`
示例：`算法-循环结构-第1课时-while与for循环.md`
