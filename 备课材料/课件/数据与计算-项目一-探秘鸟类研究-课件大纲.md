# 课件大纲：探秘鸟类研究——认识数据、信息与知识

> 按 4 课时组织，可在此基础上配图（鸟类照片、记录表截图、图表示例）

## 第1课时：项目立项
1. 情境导入：候鸟迁徙短视频 + 提问"你知道鸟类的哪些信息？"
2. 项目任务发布：探秘本地鸟类（真实问题）
3. 概念初识：
   - 一组鸟类观察记录 → 这些都是"数据"
   - 数据 = 记录客观事物的符号（数字、文字、图形、声音…）
4. 小组分工与计划书填写
5. 小结：身边的鸟类现象都能用数据记录

## 第2课时：数据收集
1. 记录表设计要点：时间、地点、种类、数量、天气、备注
2. 数据收集方法：观测法 / 资料法（图鉴、网络）
3. 数据录入：电子表格
4. 数据整理：重复、缺失、异常
5. 核心概念：数据是信息的载体

## 第3课时：分析提炼
1. 统计方法：计数、排序、求平均
2. 图表表达：柱状图、折线图
3. 提炼信息：从图表读出"有意义"的结论
4. 生成知识：规律性、可指导实践
5. 关系总结：数据 → 信息 → 知识

## 第4课时：成果展示
1. 展示要求：问题 → 数据 → 结论（3分钟）
2. 小组汇报与追问（这句话是数据/信息/知识？）
3. 评价量表互评
4. 总结升华：用数据看世界 + 爱鸟护鸟
5. 板书：数据—载体→信息—提炼→知识—指导→实践
