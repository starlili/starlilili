# 高中信息科技 · 教学工作流

一套可复用的标准化教学工作流，覆盖备课、作业测验与资源库管理。

## 目录结构
```
.
├── 备课材料/         备课成果归档
│   ├── 教案/        教学设计
│   ├── 课件/        PPT / 演示文稿
│   └── 学案/        学生学习单
├── 作业与测验/       课后作业与考试测验
│   ├── 作业/        课下作业
│   └── 测验/        单元 / 期中 / 期末试卷
├── 资源库/           长期积累的教学资源
│   ├── 知识点/       知识条目（按模块归档）
│   ├── 题库/         题目（含难度 / 标签 / 解析）
│   └── 素材/         图片、代码、视频等原始素材
└── 工作流/           流程规范与模板
    ├── 备课流程.md   标准备课步骤
    └── 模板/         教案 / 作业测验 / 资源库 模板

## 使用流程
1. **备课**：读 `工作流/备课流程.md`，按 `教案模板.md` 填教案
2. **配套**：从 `资源库/题库/` 抽题 → 放入 `作业与测验/`
3. **积累**：新知识点 / 新题持续归档进 `资源库/`

## 命名规范
`<模块>-<单元>-<课时>-<内容>.md`
